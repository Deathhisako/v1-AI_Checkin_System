# 论文大纲

> 《AI辅助自动化生活类签到系统：面向真实环境干扰的语义理解与自愈机制研究》

## 摘要
针对各类App/论坛/PT站每日签到场景中，传统硬编码脚本在Cookie过期、动态加密升级、
滑块/图形验证码、风控升级等真实干扰下极易崩溃的问题，提出一种基于大模型语义理解、
OCR与计算机视觉的AI辅助自动化签到系统。系统采用"感知-决策-执行-自愈"四层架构，
将语义理解引入验证码/风控对抗，构建AI驱动的登录态/加密/稳定性自愈机制，实现无人
值守下的长期稳定运行。实验表明，在相同干扰场景下，该系统签到成功率由传统脚本的1.0%
提升至99.0%，人工干预次数由98次降至1次，验证了方法的有效性。

**关键词**：自动化签到；大模型；语义理解；OCR；计算机视觉；自愈；鲁棒性

## 1 引言
1.1 研究背景（各类签到场景普及，人工重复操作耗时易遗忘）
1.2 现有方案的局限（requests直签、Cookie复用、定时任务虽成熟，但真实环境极易崩溃）
1.3 研究问题（如何让系统在Cookie过期、动态加密、验证码、风控下不崩溃、可自愈、持续运行）
1.4 主要贡献
   - 提出四层"感知-决策-执行-自愈"架构；
   - 将大模型语义理解引入验证码/风控对抗，突破硬编码OCR局限；
   - 构建AI驱动的登录态/加密/稳定性自愈机制，实现无人值守长期运行；
   - 开源原型系统与对比实验。

## 3 系统设计
3.1 总体架构（四层：应用/决策/感知/执行）
3.2 感知层设计（OCR、视觉大模型、滑块/语义验证码识别）
3.3 决策层设计（LLM语义理解、页面解析、异常诊断与处置决策）
3.4 执行层设计（请求构造、浏览器自动化、Cookie管理、加密适配）
3.5 自愈引擎（监控-诊断-决策-自愈闭环，错误分类与退避策略）

## 4 关键方法
4.1 语义理解型验证码识别
   - 题目语义解析（LLM）：理解"点击所有红绿灯"等自然语言指令；
   - 候选图语义匹配（CLIP/视觉语言模型）；
   - 拟人轨迹生成（降低风控）。
4.2 Cookie失效自适应
   - 有效性监测（状态码+页面语义）；
   - 自动恢复（重新登录/扫码/获取新Cookie）；
   - 语义选择登录方式（LLM解析登录页）。
4.3 动态加密对抗
   - 混淆JS语义分析辅助逆向；
   - 校验失败自动重析并生成新逻辑；
   - 必要时降级浏览器自动化。
4.4 长期稳定运行与自愈
   - 响应/日志语义分类（可重试/需人工/已升级）；
   - 监控-诊断-决策-自愈闭环；
   - 失败模式归纳与策略优化。
